# TIK College

## Қазақша

**TIK College** — «Кәсіптік білім беруге жасанды интеллектіні енгізудің 1000 идеясы» республикалық конференциясына арналған жоба аясында әзірленген колледж порталы. Жоба конференцияның «Цифрландыру және Smart-ТжКБ» бағытына сәйкес оқу үдерісін ұйымдастыруды жеңілдетуге арналған.

Портал студенттер мен оқытушыларға өз сабақ кестесін көруге, ал оқу бөліміне топтар, оқытушылар, пәндер мен аудиториялар туралы мәліметтерді басқаруға мүмкіндік береді. Мақсаты — оқу ақпаратын бір жерге жинақтап, кестемен жұмыс істеуді ыңғайлы ету және күнделікті қол еңбегін азайту.

GitHub Pages нұсқасы демонстрациялық режимде жұмыс істейді: деректер ашық, өзгерістер тек ағымдағы браузерде сақталады. [Кіруге арналған демонстрациялық аккаунттар](DEMO_ACCOUNTS.md).

## Русский

**TIK College** — портал колледжа, разработанный как проект для республиканской конференции «1000 идей внедрения искусственного интеллекта в профессиональное образование». Проект соответствует направлению «Цифровизация и Smart-ТиПО» и помогает упростить организацию учебного процесса.

Студенты и преподаватели могут просматривать своё расписание, а учебная часть — управлять сведениями о группах, преподавателях, предметах и аудиториях. Цель портала — собрать учебную информацию в одном месте, сделать работу с расписанием удобнее и сократить повседневную ручную работу.

Версия на GitHub Pages работает в демонстрационном режиме: данные открыты, изменения сохраняются только в текущем браузере. [Демонстрационные аккаунты для входа](DEMO_ACCOUNTS.md).
